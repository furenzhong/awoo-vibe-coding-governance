# 预览操作说明（合成项目已有 runbook）

## 环境与访问

本例仅使用 `rehearsal` 本地演练环境。入口是本目录中的 `local_service.py`；不启动端口、不访问网站。身份参数为 `preview-operator`，仅用来发现传错身份的情况，不认证任何真实账号。无需凭据，因此没有密码／令牌值或获取位置。

接手者需有 Python 3.10+ 和本次隔离目录的读写权限。隔离目录由运行者在 `init --sandbox` 时明确指定；目录找不到就报告缺口，不创建新目录冒充旧现场。

## 查询与续接

1. 从检查点确认本次原操作 ID 和隔离目录；示例操作 ID 是 `preview-041`。先运行 `inspect`，参数见[运行说明](README.md)。
2. 返回 `ready` 时，核对同一环境、身份和原操作，再用 `finish --expected-state ready` 完成其剩余步骤。
3. 返回 `completed` 时无需推进，保留原结果。检查不到状态或身份不符时不要猜测原操作是否完成。
4. 复查状态为 `completed`、原操作 ID 未变且 `completion_count` 为 `1`，这是本地夹具的成功判断。它不代表任何真实业务验收。

不要把“控制会话没有最终回复”推断成操作未受理。探针不提供重新提交命令；真实系统中的重试规则必须来自该系统的实际操作说明。

## 验证时点与条件

示例检查点中的 `2026-09-30T10:00:00+08:00` 是合成的上次观察：环境参数和查询方式在当时的本地环境可用，之后控制会话失联。这不是发布者真实执行成功的证据。运行者应保存自己实际使用的脚本版本、命令、时点和结果；不要把示例时间复制成实测记录。
