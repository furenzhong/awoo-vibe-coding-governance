# 新会话启动提示模板

模板修订：v1.6.0 候选，保留既有路径。部署时填入目标项目的真实入口；这里只提供指令，不复制当前状态。

```text
请在当前项目继续工作。先读 canonical AGENTS，以及 project-os.json 映射的规则、STATUS 和 HANDOFF；没有映射时使用项目现有的明确入口。

从 STATUS 找当前任务和必要合同。区分已确认的意图、证据支持的事实与待核实假设。核对实际工作目录、代码基线和交接现场，再推进已授权的下一步。

若下一步依赖服务器、后台或工具，沿 HANDOFF 指针读取已有操作说明和相关检查点，核对正确环境、入口、身份、凭据获取位置、已验证步骤以及当前操作的查询方式。不要假定旧登录态仍有效，不把凭据值写入文档；无需为不涉及的操作补表。

如果已有运行会话、外部操作 ID 或交付回执，先查询并续接，不重复派工或重新调用外部服务。若文档冲突，引用具体来源，依据当前合同和证据解决；拿不到必要信息就具体说明缺口，保留未知，只暂停依赖它的动作。确实缺少用户才能提供的信息时再提出一个具体问题。

先简述当前目标、关键约束和下一步，再继续已有授权的工作，不增加例行审批。结束时只更新发生变化的职责文件。区分记录已保存、接手所需内容已核对与实际接续已验证，简短报告证据范围和剩余缺口；未做的检查写未测。不因恢复会话启动或询问文档清理。
```

用户可以直接复制此提示。若已有等效启动入口，不再安装一份。
