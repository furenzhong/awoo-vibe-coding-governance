# 当前交接模板

模板修订：v1.6.0 候选，保留既有路径。只保存停点、现场和下一步索引。已完成／进行中／优先级的项目摘要归 STATUS；任务生命周期与当前上下文版本归任务记录；稳定规则归 AGENTS 及映射的规则文件。按实际需要填写；没有独立任务或操作现场时不为模板补造记录。

## 从哪里接

- 当前状态：[STATUS 相对链接]
- 当前工作：[已有任务／专题相对链接；无需为换会话强制新建任务]
- 恢复检查点：[已有负责人检查点；执行者检查点从任务记录按身份查找；不适用可省略]
- 操作说明：[本次继续工作需要的已有部署／操作说明及具体段落；不适用可省略]
- 刚停下的动作：[实际操作及停止原因，不复制整轮成果]
- 下一步入口：[任务或验收文档中的具体位置]

## 需要保留的现场

| 现场信息 | 实际值或证据 |
|---|---|
| 工作目录与基线 | [优先链接任务记录，避免再次抄写 SHA] |
| 未提交改动 | [文件、归属和用途；没有写无] |
| 仍在运行的进程或会话 | [链接任务中的会话与运行证据；未知就先核对] |
| 已形成但尚未处理的产物 | [回执／检查点／交付路径] |
| 必要访问与未结束操作 | [链接操作说明中的环境、入口、身份、凭据定位和成功步骤；链接检查点中的操作 ID、查询方式与停点；按需使用] |
| 待送达或待采用的纠偏 | [链接任务中的纠偏记录；已写文件不等于对方已收到] |
| 继续前必须核实的事 | [真实不确定项；没有写无] |

不记录凭据值或敏感响应。稳定访问知识进已有操作说明，临时停点进检查点，这里只保留指针；不要求无服务器项目填写访问表。中断后先核实环境、身份、原操作和实际运行状态，再恢复明确会话／检查点，不能因为上一轮没有最终回答就重新执行。检查点是上次观察，不证明进程现在仍运行或已经停止；曾登录成功不证明当前会话继承登录态。

采用 [任务上下文协议](../../02_TECH/TASK_CONTEXT.md) 时，负责人和各执行身份分别维护自己的检查点，不轮流覆盖共享 HANDOFF。检查点区分已完成动作及结果、未决假设、运行操作与定位信息、下一步，并引用实际采用的上下文版本。收到旧版本交付时先核对纠偏与受影响范围，不能直接验收。

## 交接更新

只在有意义的停点或现场变化时更新；派工、实质选择和纠偏记录回各自的任务文件。规则、目标、状态、问题表和完整日志不在这里复写；需要它们时添加相对链接。没有独立交接现场的简单任务，保留 STATUS 与任务入口即可。旧任务没有检查点时据真实现场恢复，不补造历史。

用户明确要求换新对话前更新治理时，按[任务上下文合同](../../02_TECH/TASK_CONTEXT.md)检查本轮未落盘的决定、纠偏、证据、操作依赖和现场，更新原职责文件，再核对入口能否找到接手所需信息。重点保存缺失后会造成重问、重复试错、错环境或重复执行的信息。拿不到的历史明确标未知。

给用户的简短回执可以是：

```text
接手入口：[实际路径]
已保存：[有变化的来源与内容]
已核对：[检查范围；具体缺口或无已知缺口，不能等同于完整无损]
实际接续：[在哪个环境完成了什么及证据，或未测]
```

这是本次交接结果的简述，不要求另存一份文档。已保存、已核对与实测接续独立；交接写完不表示另一个执行者已经读取或采用。

交接维护不启动文档盘点、清理、合并或归档，也不因此询问用户是否整理；这些操作仍只在用户主动请求后进行。不要求每轮总结，不依赖压缩前钩子。
