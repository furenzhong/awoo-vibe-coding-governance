## 已确认的设计

- 源工具包与目标项目身份分离，接入保留目标 Git、已有文档和业务内容。
- 一项事实只维护一处；当前状态、交接和历史承担不同职责。
- 模型与 CLI 可替换；委派通过基线、写入归属、回执和验收证据接回。
- 当前权威、当时派工依据和最后执行现场分别保存；共享文件更新不等于执行者收到纠偏，checkpoint 不等于实时进程状态。
- 文档和机器检查本身不能证明治理有效，需要独立接手与异常演练。
- 文档盘点与清理仅由用户明确请求唤醒；唤醒后先查证据，仅在意图、独有约束或授权无法裁定时提问，等待期间保留原文并继续独立工作。

## 待验证假设

增量接入和精简入口能减少真实项目里的用户纠偏与重复工作。当前尚无一段时间的使用数据，不能宣称已经提升开发效率。
